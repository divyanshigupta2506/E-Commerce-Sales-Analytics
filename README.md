 E-Commerce Sales Analytics

 Project Overview

This project is an E-Commerce Sales Analytics Dashboard created using SQL and Power BI.

The main goal of this project is to analyze sales data and find useful business insights related to customers, products, sellers, and delivery performance.

I used SQL to answer business questions and Power BI to create interactive dashboards for better data visualization.
